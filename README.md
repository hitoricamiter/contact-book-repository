# ContactApp

Android-приложение для управления контактами с использованием Room Database и Kotlin. Пользователь может добавлять, редактировать и удалять контакты, а также просматривать их в списке.

## Особенности
- Сохранение контактов локально с помощью Room Database.
- Добавление, редактирование и удаление контактов.
- RecyclerView с кастомным адаптером для отображения контактов.
- Диалоговое окно для ввода и редактирования данных контакта.
- Использование Kotlin Coroutines для работы с базой данных в фоне.

## Технологии
- Kotlin
- Android SDK
- Room Database
- RecyclerView
- Android View Binding
- Coroutines (lifecycleScope + Dispatchers.IO)
- Swipe left to delete
